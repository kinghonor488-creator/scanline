# 用 ChatGPT 生成角色插画

8 位原创角色，统一为「层叠剪纸」二次元风格。每位角色生成一张**竖版 2:3（1024×1536）**全身插画，
游戏会把它用在角色选择、主菜单、开场动画、连击切入、结算页和游玩背景里。

## 操作步骤

1. 打开 ChatGPT（需要能生成图片的版本），新建一个对话。
2. 先发送下面的【通用风格】+ 第一位角色的描述，生成第一张。
3. 满意后，**在同一个对话里**继续发：「保持和上一张完全相同的画风、边框和质感，画下一位角色：」+ 下一位角色的描述。
   这样 8 张图风格会更统一。
4. 每张图下载后，按角色 ID 重命名保存为 PNG，例如 `yuexian.png`，放进这个文件夹（`assets/characters/`）。
5. 告诉 Claude「图片放好了」，由 Claude 更新配置并发布。也可以自己把 ID 加进 `custom.json`，例如 `["yuexian", "qingdai"]`。

> 注意：不要在提示词里写任何现有动漫角色或画师的名字，保持原创，避免版权问题。
> 如果某张不满意，可以说「重新画，脸更精致一些 / 衣服颜色更偏蓝」之类继续调整。

## 通用风格（每次都带上）

```
请画一张竖版 2:3 比例（1024×1536）的二次元插画。
风格：层叠剪纸艺术（layered paper-cut art / papercraft），画面像多层手工剪纸叠出的立体浮雕，
有细腻的纸张纹理、柔和的层间投影和少量烫金细节；四周是华丽的镂空花纹边框，点缀花朵、蝴蝶和星光。
人物：一位原创的动漫少女，脸部精致美丽，大而有神的眼睛带细腻高光，五官秀气，表情温柔自信；
身材修长、比例优雅；长发或衣摆有飘逸的动感。
构图：全身像，人物在画面中央，脸位于画面上方三分之一处，四周留出边框装饰。
不要任何文字、标志、水印或签名。
```
