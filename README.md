# SCANLINE

A Cytus-style rhythm game that runs in the browser. Import any song you own and the game
analyzes it (beats, BPM, sustained notes) and generates Easy / Hard / Chaos charts automatically.

- Four original anime characters, each with her own animated stage
- Music player with a 10-band EQ, loudness normalization, spatial modes and crossfade
- Works offline once installed (Add to Home Screen on iPhone)

Imported songs stay on your own device; nothing is uploaded.

## Run locally

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000.
